# Media Organizer

A tool to organize messy files

---

## Overview

Usually after some months my downloads folder looks like a kitchen junk drawer, this tool sorts all this clutter into configurable categories.

This is also an exercise for myself to test my python skills including: classes, file I/O, CLI arguments, ...

---

## Features

- Recursively finds files
- Finds category based on extention
- Moves files into new folder structure

---

## Tech Stack

- Language: Python
- Libraries: shutil, pathlib, json

---

## Usage

```
python main.py --source "path" --destination "path"
```
